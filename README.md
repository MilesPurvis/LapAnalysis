# LapAnalysis

> **RaceStudio in your browser—compatible with any platform.**

Download sessions from AiM devices over Wi-Fi without RaceStudio 3 and browse them in a local web app. Features include laps, a speed-coloured GPS map, synced channel charts, and optimal segments. **Works completely offline.**

---

## 🚀 Quick Start

```bash
cd app
cargo build --release && ./target/release/lapanalysis
```

Open your browser at: **[http://127.0.0.1:8080](http://127.0.0.1:8080)**
